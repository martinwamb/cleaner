# Cleaner Platform

Frontend prototype for a cleaning-business website and operator workspace.

## Local development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## Validation

```bash
npm run build
```

The current app uses mock data and local state. It does not contain authentication, persistence, payments, or production customer data.
