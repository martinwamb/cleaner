# Cleaner Platform

Frontend platform for a cleaning-business website and operator workspace.

## Local development

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:5173`.

## Validation

```bash
npm run build
```

The current app uses controlled seeded data and browser persistence while the internal access and production service boundaries are completed. Payments remain offline and no production customer data is used.
